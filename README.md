# Student Performance Dashboard

## Project Overview
An Excel-based data analytics project focused on analyzing student academic performance and presenting insights through a dashboard.

## Tools Used
- Microsoft Excel
- Data Cleaning
- Excel Formulas
- Charts and Graphs
- Data Visualization

## Project Objectives
- Analyze student academic performance.
- Identify performance trends.
- Present important insights using visualizations.
- Create an interactive dashboard for better understanding of student data.

## Project File
- `Student_Performance_Dashboard.xlsx` – Main Excel project containing the dashboard and analysis.

## Key Learnings
- Understanding data analytics fundamentals.
- Working with Excel datasets.
- Data visualization and dashboard creation.
- Extracting meaningful insights from data.
